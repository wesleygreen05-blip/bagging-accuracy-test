Bagging Accuracy Challenge

This challenge is designed to help us understand which bagging details are easiest to miss under pressure. It includes order matching, rapid decisions, interruptions, and memory recall. It is not a pass/fail test.

How the Test Works

  1. Read carefully, but work quickly. Every order check is timed.
  2. Compare the guest's order with what is shown in the bag.
  3. Some orders have one or more mistakes. Other orders are completely correct.
  4. For GOOD / ERROR questions, choose GOOD only when everything matches.
  5. You may receive an interruption or order change. Pay attention before continuing.
  6. At the beginning, you will receive details to memorize. The next question will NOT ask about them. Keep them in mind throughout the entire test because you will recall them at the very end.
  7. Do not write down the memorization details or save them on another device.
Important: Accuracy matters most, but response time is also recorded. Treat each question like a live bagging situation.
Manager note: for the initial team rollout, use results as a coaching and baseline tool. Do not treat the first attempt as pass/fail. Compare patterns across the team before setting any future benchmark.
